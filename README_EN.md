# Awesome-Fable5.2-Game

**An index of AI-generated playable web games — play instantly · by genre · verbatim prompts**

Community web games generated by AI from a single prompt. Every case links to a verified playable build with its verbatim prompt; model attribution follows the original authors.

- 🌐 Gallery: https://zqingdut.github.io/Awesome-Fable5.2-Game/
- 📖 中文：[README.md](README.md)
- 📥 Submit a game: [issue form](https://github.com/zqingdut/Awesome-Fable5.2-Game/issues/new?template=submit_case.yml)

> Fan tributes are not affiliated with the original titles; games belong to their original authors. The index is MIT-licensed.

## Rules

- Every entry must be **playable in the browser** (single-file HTML or a directly accessible deployment).
- Play links are verified one by one (HTTP 200) before they are listed.
- Prompts are copied verbatim — never rewritten, truncated, or translated; unpublished prompts are marked as such.
- Model attribution follows the original authors; nothing is guessed or claimed.
